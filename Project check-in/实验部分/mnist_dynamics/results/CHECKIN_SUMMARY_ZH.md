# 可直接放入Check-in的中文总结

在MNIST三层ReLU网络上，我们完成34条本地运行，主要比较各用3个随机种子。与Figure 3d一致，大初始化出现训练先拟合、测试后改善：alpha=8参考运行在3,500步拟合训练集，到36,685步才首次观测到测试准确率超过60%。与Figure 3e一致，N由500增至4,000时，t60均值由38,500降至3,500步；N=200的3次运行在十万步内均未达阈值。主要差异是小初始化末期出现测试性能回落，大N平台也尚未完整验证，N=8,000仅作单seed补充。子集与随机/评估协议差异可能改变具体曲线，尚未通过受控实验区分。因此，本结果支持主要定性趋势，但不足以证明全局范数是唯一机制。

口径：保留34条=3d 18条+3e主实验15条+补充1条；另外8条按用户要求取消。t60为首次观测到测试准确率严格>60%的优化步数；N200为预算内右删失，不代表永远不能泛化。三seed均达到时才报告普通均值/样本SD。

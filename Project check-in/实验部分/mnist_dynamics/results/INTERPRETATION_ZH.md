# Figure 3d–e 结果解读与论文原图对照

结论：**主要定性现象复现成功；原图的逐点数值、完整大数据平台及范数唯一因果解释尚未验证。** 本次保留34条完成运行：3d为6个初始化倍率×3 seeds；3e主实验为N=200/500/1000/2000/4000各3 seeds，N=8000 seed0仅作补充。用户取消的8条不计为阈值未达到。

原图依据：用户提供论文PDF第5页Figure 3d–e及第4–5页正文，附录A的MNIST设置；公开引用为[Liu、Michaud与Tegmark，ICLR 2023](https://arxiv.org/abs/2210.01117v2)。代码依据为[固定版本的官方notebook](https://github.com/KindXiaoming/Omnigrok/blob/3a0a57346230a7255e5390fcd565812d00f1a281/mnist/grokking/mnist-grokking.ipynb)。以下不把从原图视觉读取的位置当作原始精确数值。

## 1. 哪些现象复现成功

| 原图要说明的现象 | 本地证据 | 判断 |
| --- | --- | --- |
| 3d：大初始化使训练拟合与测试改善分离，产生延迟泛化 | alpha=6/8/10的全部3 seeds均先达到训练拟合标准，之后才越过测试60%；t60均值为17,342、35,351、59,363步 | 定性成功，且在本次三个种子中方向一致 |
| 3d：小初始化较早学习，不出现同样长的低测试平台 | alpha=1/2的t60均值仅4.33/6步，早期测试准确率约91%；alpha=4也较早越过60% | 早期趋势成功；不能据此声称末步性能一定更好 |
| 3e：增加数据量可缩短达到测试阈值的更新数 | N=500/1000/2000/4000的t60均值依次为38,500/28,333/19,000/3,500步；三个seed在这些已达到的N点上均同向下降 | 用户保留的主实验区间内成功 |
| 3e：小数据附近等待时间急剧增加，并存在预算内未达到的运行 | N=200的3条均在100,000步内未达60%，末步测试准确率50.14%–52.83%；N=500的3条均达到 | 有限预算下的转变成功；不能据此确定理论临界数据量或证明永不泛化 |
| 3e：更大N处趋于数千步的平台 | N=4000均值3,500步；N=8000仅seed0为2,500步；后续大N任务已取消 | 仅有与平台相容的迹象，尚未验证原图直到N≈30,000的完整平台 |

这里t60严格表示“首次**观测到**完整测试准确率>60%的优化步数”，不是墙钟时间，也不是训练拟合之后的等待时间。拟合采用项目标准：训练准确率≥99%且element-mean MSE≤0.001。

alpha=8参考运行在第3,500步拟合，到第36,685步才观测到测试越阈，相隔33,185步。更大的alpha也延长了训练拟合本身，但并不能解释全部差距：alpha=6/8/10拟合后到t60的平均间隔仍约14,674/31,516/54,694步。

数据量的作用也不等于“更快记住训练集”。N=500/1000/2000/4000的拟合step中位数为2,000/3,500/15,000/18,500，测试t60却下降。N=4000时测试先越过较低的60%阈值，再达到更严格的训练拟合标准；这种负时间差只是两个不同标准的先后顺序。

## 2. 主要差异及其解释强度

### 小初始化的末期回落

本地alpha=1的观测峰值测试准确率均值为91.07%，末步均值为76.59%，下降14.48个百分点；逐seed下降12.22–17.41个百分点。原3d没有明显呈现本地这样的小alpha末期大幅回落，因此这部分动态没有逐点复现。alpha=2回落较轻；alpha=4在约70%的早期平台后仍进一步改善。

这也说明：**t60不能作为是否grokking的唯一二值判据。** alpha=4虽早于训练拟合越过60%，仍有后期测试提升；小alpha虽越阈很早，末步也可能退化。应同时阅读完整曲线、训练拟合时刻和末步结果。

### 已确认的协议差别

- 论文正文描述随机训练子集；本地取MNIST前N个样本，与公开notebook一致。原图实际索引未公开，数据成员差异可能影响精确曲线。
- 本地使用独立训练随机数流和显式3 seeds。官方notebook的训练与打乱评估DataLoader共同消耗全局随机数，因此即使都写seed=0，后续训练批次也不一定相同。
- 官方自定义`cycle`是while/for重新迭代DataLoader，每轮会重新shuffle；本地也如此。不能把它误当成缓存首轮的itertools.cycle，或把“每轮重新shuffle”当成双方差异。
- 官方notebook在调用处显式评估完整测试集，本地也评估全部10,000样本。差别是原notebook打乱顺序、batch=50，本地固定顺序、分块评估；不能声称原代码只评估随机2,000个测试样本。
- 本地3d主图显示三个seed的均值/样本SD，另给逐seed图；原图的alpha网格、全部重复设置未完整给出。3e本地每500步评估，原专用扫描频率未确认，t60存在观测分辨率差异。
- 原notebook记录的MSE为每样本输出平方和，本地主报告用element mean，前者是后者的10倍；双方优化用的MSE目标相同。对比loss数值时要统一单位，准确率和t60不受这项日志单位换算影响。
- FP64、网络宽深、batch=200、lr=0.001均与官方notebook/附录设置对齐。不能把“本地用了FP64”列为已经确认的作者代码差异。notebook默认wd=0.01只是通用示例；本地采用原图标题的3d wd=1e-4、3e wd=5e-3。

### 可能原因，尚未做因果隔离

数据成员、批次随机序列及其与评估的耦合，是具体数值不完全一致的直接候选来源。长时间训练中，固定学习率和AdamW的持续更新可能使已拟合模型继续移动，伴随小alpha测试退化；这是与本地MSE/范数继续变化相容的解释，**并未通过学习率、批次或优化器对照证明**。原环境版本和默认优化器内核未完整锁定，数值归约差异也可能影响长程轨迹，但不应优先把差异简单归咎于硬件或浮点精度。

3d与3e的weight decay本来不同，不能把两图同N=1000点的时间差解释成单一数据量效应。用户缩减N范围、只有3 seeds及有限训练预算，还限制了平台区间和临界行为的结论。

## 3. 与LU机制的关系

大初始化延迟、增大数据量减弱延迟，与论文LU图景相容。但3d–e本身不能证明全局范数是唯一原因，也不能验证完整的固定范数reduced-loss景观。

参考运行的全局范数为93.54→最低88.11→末步93.02，并非单调收缩；与此同时测试准确率升至83.86%。其第一层范数65.42→72.86、第二层65.20→57.78、第三层14.80→2.19，存在明显层间尺度重分配。

这限制的是“只看总范数单调下降就能解释全过程”的简单解读，**不是直接反驳论文原图**：3d–e并未画出范数轨迹，而论文reduced loss还涉及固定范数下的角向优化，真实AdamW轨迹不保证始终位于该最小值上。当前观察没有分离范数、方向和层间尺度的因果贡献；本轮未执行匹配范数轨迹的方向干预。
